# 30-second demo script

0–5 s: Explain that SPHEREx images change wavelength as well as observation date.
5–12 s: Open a verified real-data field. Display source, detector and observation date.
12–20 s: Show a wavelength-matched exposure pair, explaining that unavailable matching coverage is reported rather than fabricated.
20–26 s: Show the explicit simulation selector for demonstration data and export a GIF or MP4.
26–30 s: Show the repository link and describe the remaining scientific validation accurately.

Record only behaviours verified in the running application. Do not depict simulated motion as a measured discovery or imply a public deployment exists before it does.
