# 30-second demo

- **0–5 s:** “SPHEREx images change wavelength as well as date. A brightness change in a flipbook is not automatically a variable star.”
- **5–12 s:** Open Barnard's Star in real-data mode; show the detector, observation date and mask toggle. Explain that the supplied field has one visit and its bright core is masked.
- **12–20 s:** Select WISE 0855, D6, Individual Exposures. Play the observed frames; show the wavelength-variation warning. Select Wavelength Match to show either the measured matched pair or the explicit coverage limitation.
- **20–26 s:** Show the aperture measurement table and export an animation. If demonstrating injected motion, explicitly switch to Simulation and name it as simulated.
- **26–30 s:** Show the repository and validation report. “The tool preserves missing data and documents what these observations can and cannot establish.”

Record the running local application until public hosting is verified. Do not show an invented deployment URL, molecular detection, or confirmed motion result. Competition upload and attribution need team review.
